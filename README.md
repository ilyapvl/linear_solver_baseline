## Описание

Две программы:

- `dif.cpp` — численное дифференцирование
- `slae.cpp` — решение систем линейных алгебраических уравнений

## Требования

- Компилятор C++ с поддержкой C++20
- python 3.9+, пакеты numpy, matplotlib, pandas

## Сборка

```bash
g++ -std=c++20 -O2 dif.cpp -o dif
g++ -std=c++20 -O2 slae.cpp -o slae
```

## Использование

### dif

```bash
./dif <x0>
```

- `<x0>` — точка, в которой вычисляется производная
- Программа создаёт CSV-файлы для каждой функции: `func1_sin_x2_errors.csv`, ..., `func5_sqrt_x_plus_3_errors.csv`.
- визуализация: `python3 visualize_dif.py`

### slae

```
./slae -i <input_file>
```

- `<input_file>` — файл с матрицей A и вектором b.

**Формат входного файла:**

1. Первое число — порядок матрицы `n`.
2. Далее `n * n` чисел — элементы матрицы `A` по строкам.
3. Затем `n` чисел — элементы вектора `b`.

Пример:

```
3
4 1 0
1 3 1
0 1 2
1 2 3
```

**Выходные данные:**

- В консоль выводится решение и невязка для каждого метода.
- Создаются файлы `res_jacobi.txt`, `res_seidel.txt`, `res_sor.txt`, `res_grad.txt`, `res_minres.txt`, `res_cg.txt`, `res_bicgstab.txt` с историей нормы невязки.
- визуализация: python3 visualize.py

Программа `gen_m.py` генерирует входной файл для матрицы из пункта m задания
